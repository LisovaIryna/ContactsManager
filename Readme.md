# ContactsManager

## English

### Description
This project was created as part of an ASP.NET Core course on Udemy.
The application allows managing users: adding, editing, deleting, and exporting user lists to different file formats.
The project was developed for educational purposes to practice working with ASP.NET Core and web application development.

### Features
- Add users
- Edit users
- Delete users
- View user list
- Export user data to different file formats

### Technologies
- C#
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- Razor Views
- HTML
- CSS
- JavaScript

### Architecture
The project is built using the MVC (Model-View-Controller) pattern.
Entity Framework Core is used for database operations.

### Project Status
Educational project created during a Udemy course.

### Notes
Authentication and authorization are not implemented in this version of the project.
There is also another version of this project developed using Clean Architecture principles, which includes authentication and authorization functionality.

# Українська

## Опис
Цей проєкт був створений у рамках курсу з ASP.NET Core на Udemy.
Застосунок дозволяє керувати користувачами: додавати, редагувати, видаляти та експортувати список користувачів у різні формати файлів.
Проєкт розроблявся у навчальних цілях для практики роботи з ASP.NET Core та веброзробкою.

## Функціонал
- Додавання користувачів
- Редагування користувачів
- Видалення користувачів
- Перегляд списку користувачів
- Експорт даних користувачів у різні формати файлів

## Технології
- C#
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- Razor Views
- HTML
- CSS
- JavaScript

## Архітектура
Проєкт побудований з використанням патерну MVC (Model-View-Controller).
Для роботи з базою даних використовується Entity Framework Core.

## Статус проєкту
Навчальний проєкт, створений під час проходження курсу на Udemy.

## Примітки
У цій версії проєкту не реалізовані авторизація та автентифікація користувачів.
Також існує інша версія цього проєкту, реалізована з використанням принципів Clean Architecture, у якій додані функції реєстрації та авторизації.
